# **Connect Four with AI**

## **Introduction**
This project implements a Connect Four game with an AI opponent using Python. The AI leverages the MiniMax algorithm with alpha-beta pruning to make strategic decisions. The game supports two difficulty levels: EASY and HARD, making it accessible for both casual players and those looking for a challenge.

---

## **Prerequisites**
To run this project, ensure your system meets the following requirements:
- Python installed.
- Required Python libraries: `pygame` and `numpy`.
- If you are using Visual Studio Code to run the code, be sure to select that you trust the window or the code will not run.

### Installing Dependencies
Run the following command to install the required libraries:
```bash
pip install pygame numpy
```

---

## **Running the Game**
1. Open IDE in my case Visual Studio Code
2. Trust the Window(if required)

---

## **Game Instructions**
1. **Select Difficulty**: Upon starting the game, choose the difficulty level by clicking on either the "EASY" or "HARD" button.
   - **EASY**: AI makes less strategic moves, providing a more casual experience.
   - **HARD**: AI uses deeper decision-making strategies to provide a challenge.
2. **Player's Turn**:
   - Hover your mouse over the board to preview where your token will drop.
   - Click to place your token in the desired column.
3. **AI's Turn**:
   - The AI calculates its move and places a token in one of the columns.
4. **Winning the Game**:
   - Align four tokens horizontally, vertically, or diagonally to win.
   - A message ("You Win!" or "AI Agent Wins!") will be displayed at the end of the game.
